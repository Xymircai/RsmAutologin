# 测试与发布验证

在有交互式桌面的 Windows x64 环境运行：

```powershell
.\scripts\Build.ps1 -Test -OutputRoot 'artifacts\releases\v0.1.0'
```

脚本使用隔离的 .NET SDK、锁定依赖及校验过的本地模型。默认测试全部使用假账号、合成验证码和离线模拟窗口，不连接真实 EAS／新纪元服务。测试凭据使用独立随机前缀，并在结束时清理。

## 覆盖内容

- 配置读写、损坏保护、旧配置迁移、独立模块账号及 Windows 凭据管理器操作。
- OCR 四位数字识别、重复数字、置信度、100%／125%／150% 缩放与缺失模型处理。
- 账号界面、100%／125%／150%／200% 布局、绑定控件填写、一次提交及失败后停止。
- 新纪元异地授权提示的单次补填重试、错误分类、迟到结果确认及双模块互斥。
- Windows Graphics Capture 后台取图、验证码重绘去重、实际换码、持续输入活动、捕获失败及后台监听。

测试入口在 `tests/EasLoginHelper.Tests`，支持 `--no-ui`、`--background-ui-only`、`--login-ui-only`、`--dual-ui-only`、`--monitor-ui-only` 分组。核心与 OCR 测试仍要求 Windows；完整套件需要可显示窗口的交互式桌面，不能以无桌面的 CI 环境代替。

## 可选本地截图

`Build.ps1 -Test -SampleScreenshot '<本地文件路径>'` 保留旧的手动截图验收入口，要求 2560×1320 的指定旧布局，裁取位置 `(1377, 734, 126, 55)`，预期验证码 `4904`。这不是任意截图识别接口；截图仅由测试在本机读取，不加入 Git 或发行包。通常直接运行合成样本即可。

## 发布验收

1. 完整回归零失败，锁定依赖还原及漏洞审计通过，模型哈希匹配。
2. 解压完整 ZIP，确认版本 `0.1.0.0`，模型、MPL 许可、第三方许可及 `SOURCE.txt` 齐全。
3. 对解压后的 EXE 运行 `--capture-selftest`。该自检仅创建助手自己的离线窗口，结果应为 `Captured: true`，全局输入与激活请求均为零。
4. 校验 ZIP 与包内文件的 SHA-256，核对构建提交与发布标签一致。
5. 审核公开文件及 ZIP 内容，排除账号、密码、登录截图、内部记录和本机设置。

本机适配验证不等于对全部软件版本、显卡、DPI 或远程桌面环境的兼容承诺。OCR 小样本结果不代表总体识别准确率；软件升级后可能需要重新适配。真实账号登录属于额外人工验收，不是离线测试或构建脚本的一部分。
