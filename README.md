# 审计软件自动登录助手

一个 EXE 提供 EAS／审计工具箱、新纪元和网站登录。EasyAudit 与审计工具箱共用 EAS 模块的账号和开关。桌面模块通过后台控件填写，可在登录页被遮挡时工作。网站模块在 Windows 默认浏览器打开网页。

当前版本为 **v0.5.4**。发行包提供单文件 `EasLoginHelper.exe`、`BrowserExtension` 扩展、`SHA256SUMS.txt`（校验 EXE）和 `BUILD-INFO.json`；模型、字符表、使用说明和许可均已内置。支持 Windows 10（10.0.19041）及以上的 x64 环境。桌面监听需要管理员权限及已安装的对应审计软件。网站自动填写支持当作系统默认浏览器的 Microsoft Edge 和 Google Chrome。EXE 尚未签名。 [下载最新版本](https://github.com/Xymircai/RsmAutologin/releases/latest)

## 本次更新（v0.5.1–v0.5.4）

- **开机自启跟随 EXE**：把 EXE 拖到任何位置后，只要打开过一次新位置的助手，登录时就会启动它；开关会显示「需更新」并支持一键修复。
- **网站登录教程**：四步图文说明，截图内置在单 EXE 中；浅绿色按钮便于发现。
- **免手动连接浏览器**：点「打开网站」时自动完成浏览器登记，并把登记路径刷新为当前 EXE。

## 使用方式

1. 使用网站自动填写时，请下载并解压 `EasLoginHelper-v0.5.4-win-x64.zip`，将 `BrowserExtension` 保留在 EXE 旁。只使用桌面模块时可单独下载 `EasLoginHelper.exe`。无需另行安装 .NET、Python 或 OCR 模型。
2. 打开 EXE 并确认 Windows 管理员提示。主窗口选择 EAS 或新纪元，新增自己的账号并设为默认。
3. 新纪元可以“从 EAS 复制账号”。复制后独立保存，修改或删除一边不会影响另一边。
4. 照常打开 EasyAudit／审计工具箱／新纪元，直接运行或使用原来的快捷方式均可。助手自动发现 `EAS.exe`／`EAS.Updater.exe`、`RcAtpClient.exe`、`Xsjzb.exe` 对应窗口，无需在助手中选择快捷方式；进入登录页后填写默认账号密码，EAS 和工具箱在本机识别验证码后提交，新纪元无需验证码。
5. 您可继续在其他软件打字、移动鼠标，也可让聊天或其他窗口盖住登录页。目标软件最小化时等待恢复，不会自行恢复或激活它。

手动打开 EXE 会显示主窗口。关闭窗口后，两个模块继续在托盘监听。再次打开 EXE 或双击托盘图标可回到主窗口。

“立即填充”右侧的“开机自启”默认为关。点击开启后，助手会在当前 Windows 用户登录时通过任务计划程序直接在托盘启动。再次点击即可关闭。

把 EXE 拖到任何新位置后，只要**打开过一次新位置的 EXE**，开机自启就会自动改指向它，无需关闭再开启，开关照常显示「开机自启：开」。若还没打开过新位置的 EXE，开关会显示「开机自启：需更新」，点一下即可修复。同一台机器上放有多份 EXE 时，以最近一次打开的那份为准。同步记录见 `%LOCALAPPDATA%\EasLoginHelper\startup.log`。

### Rsm网站登录

1. 在主窗口或托盘菜单点击「Rsm网站登录」。打开圆角下拉框选择站点并新增账号。首个账号自动设为该站的默认账号。容诚邮箱系统支持用户名或完整的 `@rccpa.com.cn` 地址。
2. 如需自动填写，点「网站登录教程」，按四步图文说明逐步操作并切换查看：在 Edge 地址栏输入 `edge://extensions/` 并回车，Chrome 使用 `chrome://extensions/`；开启「开发人员模式」，点「加载解压缩的扩展」，选中发行包里的 `BrowserExtension` 文件夹，然后点「选择文件夹」。这个文件夹里应直接包含 `manifest.json`，浏览器中会出现「容诚网站登录助手」。请将加载扩展的浏览器设为 Windows 默认浏览器。加载完成后无需再做任何连接设置。
3. 点击「打开网站」进入系统默认浏览器。配套扩展使用助手保存的对应账号，容诚邮箱系统和 EasyGo 会尝试提交一次，也可以在助手里关闭自动提交。EasyGo 由门户生成本次认证请求。
4. 资源下载平台会填写账号和密码。请在网页手输完整的四位数字验证码，启用「手输验证码后自动提交」时，扩展会点击一次登录。关闭该选项时，手输验证码后可自行点击登录。
5. 主窗口网站页签和 Windows 右下角托盘会提示登录成功、登录失败或结果未确认。遇到额外验证时，请在浏览器继续。已登录的会话依浏览器和网站规则继续使用。

自动填写由「打开网站」发起，仅用于这三个站点的登录表单。每次点「打开网站」时，助手会自动把 Edge / Chrome 的浏览器连接登记刷新为当前 EXE 路径，因此把 EXE 拖到新位置后无需任何额外设置。未加载配套扩展或使用其他默认浏览器时，可以在打开的网页手动登录。若移动了扩展文件夹，在浏览器扩展管理页从新位置重新加载。

可从 PowerShell 运行 `.\EasLoginHelper.exe --websites`，按常规方式启动助手并切到网站页签。升级时先退出托盘中的旧版，关闭旧版网站登录窗口。启动新版后，点一次「打开网站」即可自动更新浏览器连接；只有移动过扩展文件夹时才需要在浏览器扩展管理页重新加载。如果已启用开机自启，启动新版 EXE 时会自动更新启动路径，无需手动关闭再开启。

## 窗口与屏幕适配

主窗口、账号编辑／复制及说明窗口均可拖动边框调整大小。主窗口中表格与操作区之间的分隔条、表格列宽也可拖动，布局会在本机记忆。升级后首次打开主窗口会采用新的紧凑尺寸。文字自动换行，较小工作区或较大缩放下可滚动访问内容，跨屏时按显示器 DPI 调整。账号名称、用户名和密码框会为下划线和字母下沿预留空间。

显示效果由 Windows 缩放、字体和可用分辨率决定，不能仅以显示器英寸判断。布局文件 `ui-state.json` 与账号配置分开，损坏或显示器变更不会清除账号。

## 自动登录规则

- EasyAudit 与审计工具箱共用 EAS 的默认账号、验证码和自动登录开关。两种程序各自记录登录轮次，登录成功提示不会互相触发；无需重新保存已有账号。
- 输入框和按钮通过绑定控件操作，不使用全局鼠标点击或逐字模拟键入。普通键鼠活动不再导致取消。
- 以保存的默认账号为准。登录事务中手动改写字段时，提交前会做一次最终校正；仍无法确认内容则停止提示，不反复争抢输入框。
- EAS 图片重绘、颜色变化或其他像素变化只触发复核。验证码数字与框内值相同就复用原值，不会再次清空重填；真正换码或被人工改写才更新。
- EAS 每轮自动提交一次。登录错误、结果不明时不自动重复提交；可明确点击“立即填充”重新尝试。
- 新纪元每次重新填写账号密码，不依赖软件记住的旧授权。明确出现“该账号已于……在电脑……登录，请重新输入登录信息获取授权”时，最多额外补填并提交一次。密码错误、网络错误、再次授权失败或结果不明时停止。
- 新纪元每次提交后最多等待 30 秒；托盘可继续只读确认迟到的成功结果，不增加提交次数。
- EAS 确认登录框消失且存在注销登录入口；新纪元确认进入“账套操作／帐套操作”。助手不会选择、打开或修改账套。
- 助手不主动激活目标窗口；原软件登录后自行弹出的提示仍遵循其自身行为。

## 验证码与后台捕获

EAS 使用 Windows Graphics Capture 读取指定窗口的图像，排除鼠标指针，并在内存中裁取验证码。不会使用遮挡它的其他窗口像素作为验证码，也不保存完整窗口截图。

仅支持当前样式的四位数字验证码。原图和去除彩色背景后的识别结果用于内部校验，不代表向界面填写两次；每个字符置信度须达到 0.8，两个高置信结果不能冲突。识别三秒超时、帧空白、捕获不可用或结果不确定时提示手动处理。

最小化窗口没有可用帧时等待恢复。页面持续换码、窗口尺寸或 DPI 在捕获期间变化时不冒险提交。软件升级后若不再提供可写控件，会提示停止，不回退到抢焦点或全局按键。

校准登录页仅保留为原有手动定位工具；仅有坐标的旧校准不能替代后台可写控件。当前 EAS 安装版本已识别到可写控件。

## 账号与托盘

- 两个模块各有默认账号和自动登录开关；切换管理页面不影响另一个模块监听。
- 修改账号时密码留空表示保留已保存密码。
- “立即填充”会在后台查找对应登录页；自动登录开启时，填写后也会提交，无需切回登录页。多个登录窗口无法唯一选择时会提示。
- 关闭“填写完成后自动登录”可恢复只填写模式；关闭 EAS 的验证码识别则保留手动验证码和登录操作。
- 暂停本模块或暂停全部会取消未完成流程；“退出助手”完全停止监听。
- 若要退出原软件后停留在登录页，请先暂停对应模块或关闭自动登录。

## 本机数据与诊断

- 桌面账号和设置保存在 `%LOCALAPPDATA%\EasLoginHelper\settings.json`，格式版本 2。各网站的账号和设置保存在同目录的 `website-settings.json`。
- 密码保存在当前 Windows 用户的凭据管理器。桌面账号使用 `EasLoginHelper/Account/`，网站账号使用 `EasLoginHelper/Website/站点/`。配置和诊断报告只保存元数据。
- 保留已有账号和配置。读取旧的单模块配置时保留 EAS GUID、默认账号和开关，并备份原文件为 `settings.json.schema1.bak`；双模块配置无需重新录入。
- 凭据只属于当前电脑与 Windows 用户，不随程序包复制。删除账号时同时删除对应凭据；配置损坏会保留原文件并提示。
- `runtime-status.json` 分模块记录阶段、提交次数及用户名／密码／验证码的写入次数。日志不记录这些字段的内容，也不记录按键内容。

## 验证码空白时

运行 `EasLoginHelper.exe --selftest` 启动环境自检。自检用离线模拟窗口检查内置资源、OCR 引擎、后台捕获和绑定控件写入。

报告位于 `%LOCALAPPDATA%\EasLoginHelper\environment-selftest.json`，含程序／Windows 版本、架构、DPI、工作区、捕获后端及分阶段成功状态。`Ocr.AssetsMissing`／`Ocr.AssetsInvalid` 表示资源问题，`Ocr.EngineUnavailable` 表示引擎加载问题，`Capture.*` 表示后台捕获或裁剪问题，`Ocr.LowConfidence` 表示识别未被接受。自检通过而真实 EAS 仍失败时，再运行只读 `--diagnose` 核对实际登录页面控件与版本。

OCR 首次初始化在后台进行，最多等待 20 秒，与单次识别超时分开；等待期间新纪元模块仍可工作。验证码未可信填写时停止自动提交，并显示具体环节；不通过降低置信度强行登录。

托盘助手已退出时可使用以下一次性命令；省略模块默认为 EAS：

```powershell
EasLoginHelper.exe --diagnose
EasLoginHelper.exe --selftest
EasLoginHelper.exe --website-selftest
EasLoginHelper.exe --fill-once
EasLoginHelper.exe --login-once
EasLoginHelper.exe --diagnose --module new-era
EasLoginHelper.exe --fill-once --module new-era
EasLoginHelper.exe --login-once --module new-era
```

`--diagnose` 只读控件结构和通用状态，不填写或登录；EAS 诊断包含隐藏／最小化窗口以排查窗口状态。报告为 `diagnostics.json`、`diagnostics-new-era.json`。
`--selftest` 完整检查内置 OCR、捕获与模拟字段写入，退出码 0 表示通过，非 0 表示未通过。旧的 `--capture-selftest` 继续提供仅捕获检查，结果写入 `capture-selftest.json`。

在当前 Windows 桌面的普通权限下运行 `--website-selftest` 可离线检查后台进程连接、浏览器消息处理、账号隔离、一次性提交、结果和超时。报告为 `website-selftest.json`。

`--fill-once` 仅填写账号密码，不提交；`--login-once` 使用与常驻监听相同的后台流程填写并登录，EAS 会识别当前验证码。一次性结果为 `last-fill.json`、`last-fill-new-era.json`，包含写入／提交次数；不会包含账号密码或验证码内容。助手已在托盘运行时返回对应模块 Busy，不并发输入。

新纪元账号库为空且托盘已退出时，`--copy-eas-default --module new-era` 可将 EAS 默认账号复制为独立凭据，不接受明文密码参数。

## 构建与验证

本机 Windows x64、.NET 10 WinForms，目标 Windows SDK 10.0.19041。程序包自带 .NET 运行时和本地 OCR。OCR 原生库遥测已关闭。

```powershell
.\scripts\Build.ps1
```

构建脚本优先使用已安装的 .NET SDK 10.0.404；没有时下载经过哈希校验的 SDK 并缓存到 `%LOCALAPPDATA%\RsmAutologin\BuildSdk\10.0.404`，后续构建直接复用。编译和发布中间文件使用系统临时目录，结束时自动清理，不在项目中长期堆积 `.tools`、`bin` 或 `obj`。依赖版本及内容哈希位于 `packages.lock.json`，模型校验位于 `assets/models/manifest.json`，第三方说明见 `THIRD-PARTY-NOTICES.md`。

默认在 `artifacts/EasLoginHelper-v<版本>-win-x64` 下输出 EXE、SHA-256 校验、构建信息和 `BrowserExtension`；发行时可传 `-OutputRoot artifacts\releases\v<版本>` 指定目录。桌面模块和打开网站使用 EXE，网站自动填写需加载同目录的配套扩展。

停止使用时，先关闭开机自启，再退出助手并移除程序包。如需清除已保存的密码，请先在账号管理中删除相应账号。
